# 在预览页编辑并导出模型

已支持 [区域压平与拖拽导出](tileset-flatten.md)：沿用区域绘制与任务流程，通过竖直手柄调整目标面，导出实际几何及边界侧壁。

预览页承担模型操作入口。当前新增范围裁剪；顶层重建、纹理压缩仍通过已有处理页执行。后续压平等能力可以沿用“选择操作 → 设置范围和参数 → 后端任务 → 独立成果 → 打开成果”的流程。

## 使用

1. 从成果列表打开模型，或在桌面预览页选择本地 `tileset.json`。本地模型会登记为成果，再通过资源服务加载。
2. 等待模型加载完成，点击 **模型操作 → 范围裁剪并导出**。
3. 矩形：在视图中按住左键拖出矩形。多边形：左键点选顶点，右键或点击“完成绘制”闭合。
4. 拖动黄色控制点调整范围，或撤销、清空重画。自交、自接触、零面积、重复顶点及过大范围会阻止导出。
5. 选择新的成果目录，点击“导出裁剪模型”。任务执行真实几何裁剪，原模型不修改。
6. 任务完成并登记成果后，点击“打开裁剪后模型”，在同一预览页查看新模型。

区域为 WGS84 经纬度，按后端局部 ENU 竖直平面裁剪，不限制高度、不生成封口。首版仍受 [裁剪功能](tileset-clip.md) 的格式、地理定位和 10 公里半径限制。视图中的黄色填充是范围指示，不是最终裁剪模型的实时渲染。

预览临时套用 ENU 定位的模型不允许地理裁剪；必须先修正源数据的地理定位。只提供外部 URL 而无本地输入路径的预览不能创建裁剪任务。地图底图与在线服务不是绘制或导出的必要条件。

## 扩展约定

- `TilesPreview` 负责加载、选择模型与操作面板生命周期。
- `PreviewClipPanel` 负责区域、输出与任务状态；其他操作使用自己的参数面板。
- `preview-drawing.mjs` 管理自己的输入处理器和绘图实体；关闭操作恢复相机输入，不清空其他预览实体。
- 父页面与 Cesium iframe 的消息需同时验证来源窗口和 origin。切换模型销毁旧操作，避免将旧区域提交给新输入。
- 后端处理完成后复用成果登记与资源服务打开输出。后续压平必须实际修改并导出几何，不只使用 Cesium 显示效果。

## 验证

`npm test` 覆盖区域坐标、凹多边形、自交、大小限制和消息结构。

`npm run test:e2e` 中 `preview-clip.spec.mjs` 使用实际 Cesium、实际 GLB 瓦片和实际 processor：鼠标绘制矩形、导出与打开成果，多边形撤销/拖点/校验，拒绝伪造消息，禁止预览临时 ENU 模型裁剪。

浏览器测试替代桌面任务传输与本地资源服务，不替代 Cesium 或几何处理器。原生文件选择器、WebView 操作和大规模实际数据仍需手动验收。
