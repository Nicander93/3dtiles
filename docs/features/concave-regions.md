# 凹多边形区域

预览页的多边形绘制、范围裁剪 GeoJSON 输入，以及 `clip-tileset` / `flatten-tileset` 任务均支持简单凹多边形，例如 L 形和 U 形地块。顺、逆时针都可用，无需手动拆成凸区域。

限制仍为一个闭合环、3–256 个不同顶点、无孔洞、无自交和自接触，距顶点平均经纬度中心不超过 10 公里。近乎共线且无法可靠分解的轮廓会报错，需微调顶点。格式、坐标和源模型限制见 [裁剪](tileset-clip.md) 与 [压平](tileset-flatten.md)。

后台在相同局部 ENU 坐标下校验轮廓，凸区域保留原处理路径；凹区域按耳切法分解为互不重叠的三角区域。裁剪组合各部分交集；压平保留它们的并集外几何，仅沿原始轮廓补连接侧壁，内部拆分线不补墙。输出凹口不会被填成包围矩形。

压平预览采用凹多边形目标面与射线奇偶规则遮罩，支持任意绕向。高度仍通过竖直手柄拖动，精确侧壁和纹理以导出为准。

验证包括面积与属性守恒、凹口保留、内部接缝不补墙、顺逆时针 CLI 导出，以及实际 Cesium 中手绘凹多边形后裁剪/压平、检查 GLB 面积并打开成果。原生桌面交互和大规模真实数据仍待手动验收。
