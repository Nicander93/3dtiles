# 区域压平与导出

在模型预览的 **模型操作 → 区域压平并导出** 中绘制矩形或多边形，显示压平工具，拖动青色竖直箭头或圆点调整目标面。俯视时可上下拖动圆点。拖动期间锁定相机，释放或关闭工具恢复输入；支持撤销高度调整和恢复原高度。高度只读显示，无需手输。

青色目标面、示意侧壁和区域内原表面的遮罩实时更新。精确分割、纹理与连接侧壁以导出模型为准。导出到尚不存在的新目录，任务完成后在同一预览页打开成果。重新创建任务会打开源模型预览，需要重新绘制区域和拖动目标面；任务详情保留原区域与高度供查看。

## 几何规则

- 使用区域顶点平均经纬度处的局部 ENU 坐标。目标高度是相对该中心 WGS84 椭球面的米数，沿当地竖直方向计算；不是海拔或大地水准面高程。高度范围为 ±10000 米。
- 分割跨越区域边界的三角形，保留区域外几何，将区域内顶点移至同一水平面。处理所有 LOD 和外部 tileset，重新计算内容包围体，保持原输入不变。
- 仅在区域边界生成连接侧壁，内部三角形接缝不补墙。边界原高度跨越目标面时分段生成，避免交叉侧壁。退化三角形移除。
- 保留材质、颜色与表面 UV；新侧壁沿用原表面材质，UV 按边长和高度差以米铺设。修改面的法线及切线重新计算，支持法线贴图使用 UV0/UV1 和纹理缩放旋转。
- 输出独立资源和 `flatten-report.json`，包含处理内容数、压平三角形数、侧壁数及高度。验证成功后原子提交；已有成果不覆盖。

首版面向地形和单层静态表面。多层建筑或重叠面会被移到同一高度，可能产生共面重叠；不执行实体布尔、面去重或完整封闭体重建，不保证水密。

## 支持范围

沿用 [范围裁剪](tileset-clip.md) 的静态 GLB / 无批次 B3DM、显式瓦片树及地理定位限制。区域为矩形或 3–256 个顶点的多边形，无孔洞，距中心不超过 10 公里，不跨日期变更线。压缩几何、动画、实例和批次元数据暂不支持。预览临时 ENU 定位的模型需先修正源数据定位。

## CLI

`region.json` 使用裁剪功能的区域格式：

```json
{"type":"rectangle","bounds":[116.99,34.99,117.01,35.01]}
```

```powershell
processor flatten-tileset -i D:\data\source\tileset.json -o D:\data\flattened --region D:\data\region.json --height-meters -5
```

桌面任务使用 `operation: "flatten-tileset"`，`options.flatten` 包含 `region` 和 `heightMeters`。

## 验证

处理器单测覆盖区域分割、坐标逆变换、接缝侧壁与法线切线。CLI 集成测试覆盖升降、区域外保留、材质与 UV、非零经纬度及旋转缩放节点、全 LOD/外部 tileset、成果可搬移、路径和参数拒绝。

Playwright 使用实际 Cesium 和 processor，覆盖俯视及斜视拖拽、相机锁定与恢复、撤销、重置、区域失效、关闭清理、导出侧壁和打开新模型。原生 WebView、文件选择器和大规模真实数据仍需手动验收。
